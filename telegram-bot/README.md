# 🤖 Telegram Captcha & Broadcast Bot

Бот для Telegram с функциями:

## ✨ Возможности

### 🔐 Капча для вступления в канал
- При отправке заявки на вступление бот присылает картинку с цифрами
- Пользователь вводит цифры — заявка одобряется автоматически
- Максимум 5 попыток, можно обновить капчу
- При провале — заявка отклоняется

### 📢 Рассылка (для админов)
- Кнопка «РАССЫЛКА» в главном меню
- Поддержка: текст, фото, видео, документы, аудио, стикеры
- Предпросмотр перед отправкой
- Статистика доставки (доставлено / заблокировали / ошибки)
- Автоматическая очистка заблокировавших бота пользователей

### ✏️ Настраиваемое приветствие
- Редактирование прямо в боте
- Поддержка HTML-разметки и эмодзи
- Тестирование перед сохранением
- Сохраняется в базе данных

### 📊 Статистика
- Количество пользователей бота

## 🚀 Установка и запуск

### 1. Клонировать / скачать проект

### 2. Установить зависимости
```bash
cd telegram-bot
pip install -r requirements.txt
```

### 3. Настроить `.env`
Скопируй `.env.example` → `.env` и заполни:

```env
BOT_TOKEN=123456:ABC-DEF...        # Токен от @BotFather
CHANNEL_ID=-1001234567890           # ID канала
ADMIN_IDS=123456789,987654321       # ID админов (через запятую)
WELCOME_MESSAGE=Привет! 👋          # Стартовое приветствие (опционально)
```

#### Как получить `CHANNEL_ID`:
1. Добавь бота в канал как администратора
2. Перешли любое сообщение из канала боту [@userinfobot](https://t.me/userinfobot)
3. Или используй API: `https://api.telegram.org/bot<TOKEN>/getUpdates`

#### Как получить свой `user_id`:
Напиши [@userinfobot](https://t.me/userinfobot) в Telegram

### 4. Настроить канал
1. Добавь бота как **администратора** канала
2. Дай боту права: **приглашение пользователей** (Invite Users via Link)
3. Включи **одобрение заявок** на вступление в настройках канала

### 5. Запустить бота
```bash
python run.py
```

## 📁 Структура проекта

```
telegram-bot/
├── run.py                  # Точка входа
├── requirements.txt        # Зависимости
├── .env.example            # Пример конфигурации
├── pyproject.toml          # Настройки pytest
├── bot/
│   ├── main.py             # Запуск бота, сборка роутеров
│   ├── config.py           # Загрузка конфигурации из .env
│   ├── database.py         # Async SQLite (пользователи, настройки, капчи)
│   ├── captcha/
│   │   └── generator.py    # Генерация изображений капчи (Pillow)
│   ├── handlers/
│   │   ├── start.py        # /start, меню, статистика
│   │   ├── captcha.py      # Обработка заявок и проверка капчи
│   │   ├── broadcast.py    # Рассылка сообщений
│   │   └── welcome.py      # Редактирование приветствия
│   ├── keyboards/
│   │   └── __init__.py     # Inline и Reply клавиатуры
│   └── states/
│       └── __init__.py     # FSM-состояния
└── tests/
    ├── conftest.py         # Фикстуры и конфигурация
    ├── test_captcha.py     # Тесты генератора капчи
    ├── test_database.py    # Тесты базы данных
    ├── test_config.py      # Тесты конфигурации
    ├── test_keyboards.py   # Тесты клавиатур
    └── test_states.py      # Тесты FSM-состояний
```
